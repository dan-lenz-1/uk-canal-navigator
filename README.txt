UK Canal Navigator V4.4

Bug fixes from V4.3:
- Restores poiStatus, poiCount and Refresh POIs elements required by the POI loader. Removing them in V4.3 caused the loader to stop before the API request.
- Every selectable map-key icon now has an independent state:
  Marina
  Water
  Toilets
  Showers
  Pump-out/Elsan
  Refuse
  Fuel
  Pubs/food
  Laundry
  Shops
  Attractions
- Locks remain permanently enabled.
- Turning off Toilets no longer turns off Water, Fuel, Pump-out, Refuse or Showers.
- V4.2 independent food/shop/laundry/attraction loading retained.
- V4.3 itinerary planner and PDF/print functionality retained.
